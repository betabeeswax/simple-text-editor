# Simple Text Editor

A basic HTML text editor that runs in your browser.

## Features
- Bold, italic, underline
- Change font size and text color
- Align text (left, center, right)
- Bullet and numbered lists
- Add photos and move them by dragging
- Add simple shapes (rectangle, circle, triangle) and move them
- Save / export as:
  - **HTML** (webpage file)
  - **TXT** (plain text)
  - **PDF** (using browser Print → Save as PDF)

## How to use
1. Open the file `index.html` in any browser (Chrome, Edge, Firefox, Safari).
2. Or visit the live page if GitHub Pages is enabled.
3. Type, format text, add photos or shapes, then use the Save buttons.
